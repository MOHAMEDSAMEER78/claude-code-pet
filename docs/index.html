How it works

No first-party API — so it watches a folder instead

Claude Code is a CLI. There's no window to hook into, so ClaudePet bridges it with hooks (writing state) and a menu-bar app (watching state).

1

A hook fires

Claude Code already runs hooks on every prompt, tool call, and permission check — one JSON snippet merged into your settings wires them up.

2

A tiny script writes state

A stdlib-only Python bridge writes one small JSON file per session — fast enough to never add latency to your turn.

3

The pet reacts, instantly

A Unix socket ping wakes the app the moment the file changes, so the pet's pose and status line update in milliseconds, not on a poll.

~/.claude/pet/sessions/<id>.json
# PermissionRequest hook fires -> session_id: "a1b2c3d4" state: "waiting-permission" action: "Needs permission: running `rm -rf tmp/`" tty: "/dev/ttys002" # -> notify-requests.sock ping # -> native notification fires # -> pet shows its waiting pose
Features

Everything you'd want from a status pet

Built to mirror the real Codex desktop pets, adapted for a CLI-first tool with no first-party app window of its own.

Reacts to your session

Idle, working, needs permission, ready for review, or failed — each with its own pose, a color-matched menu-bar icon, and a plain-English status line.

Permission notifications

A native macOS notification the instant Claude Code needs a decision — rare under auto mode, but impossible to miss when it happens. ClaudePet never decides for you.

Activity tray

Every active session, ranked by urgency. Click a row to jump straight to that terminal or IDE window.

Session command palette ⌘⇧K

A Spotlight-style fuzzy jump to any active session by project name — built for when you've got more than two or three going.

Session stats & spend

Sessions today/this week, tasks completed, and an estimated token/cost readout — all local, all from your own machine, never uploaded anywhere.

Multi-session pets

Prefer one pet per session instead of a single aggregate? Toggle a mode that lays them out in a row.

Pet gallery

Browse and preview every installed pet before applying it — drop in your own spritesheet, or reuse real Codex-format pets, same manifest and conventions.

One-click hook setup

An in-app installer wires the hooks into your Claude Code settings for you — plus a health check for "the pet just isn't reacting."

Launches with your Mac

Turn on Launch at Login from Preferences and it's just always there — no need to remember to open it.

Install

Two minutes, no App Store

A plain .app bundle plus one hook snippet merged into your Claude Code settings.

zsh — install
# 1. Download and open the app open ClaudePet.dmg # drag ClaudePet.app to Applications, launch it # 2. Wire up the hooks # Menu bar -> "Hook Setup & Diagnostics..." -> Install # (backs up settings.json for you, automatically)

Ad-hoc signed, not notarized — right-click → Open on first launch, or run xattr -dr com.apple.quarantine on the app.

zsh — build from source
# Requires macOS 13+, Swift 5.9+ git clone https://github.com/MOHAMEDSAMEER78/claudepet cd claudepet ./build_app.sh release open ClaudePet.app

Xcode Command Line Tools is enough — no Xcode project needed. Full hook wiring and custom-pet instructions are in the README.
